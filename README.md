# 資料キット

👉 **配布ページ: https://sankaku-tech.github.io/shiryo-kit/**（ボタン1つでプロンプトをコピーできます）

調べものや相談がチャットの中で終わってしまうとき、**そのまま人に見せられる1枚の資料ページに変える**ためのキットです。

使い方は2通り。**どちらか片方でいい**です。

---

## A. チャットに貼るだけ（ChatGPT / Claude / Gemini）

ふだんブラウザでAIを使っている人はこちら。インストールは要りません。

👉 **[PROMPT.md](PROMPT.md)** を開いて、枠の中をコピーして送るだけ。

調べものが一区切りついた直後に貼ると、その内容が章立てのある資料ページになって出てきます。

---

## B. Claude Code のスキルとして入れる

Claude Code を使っている人はこちら。毎回プロンプトを貼らなくてよくなります。

1. `shiryo/` フォルダごと、プロジェクトの `.claude/skills/` の中にコピーする
2. Claude Code で「資料にして」または `/shiryo` と打つ

`shiryo/template.html` が器で、Claude がその中身だけを差し替えます。

---

## 何ができるか

内容に応じて、この8つの部品から**合うものだけ**が選ばれます。ふだん使うのは3つまでです。

| 部品 | 使われる場面 |
|---|---|
| 要約カード | 要点が3つに絞れるとき |
| 本文＋補足 | 説明が続くとき。補足・注意は右の箱に逃がす |
| 段組 | 3つの段階・手順があるとき |
| 対比 | やる/やらない・前/後があるとき |
| 表 | 項目 × 観点で並ぶとき |
| 年表 | 時系列があるとき |
| 画面モック | マニュアルで画面の場所を指したいとき |
| 出典 | 根拠を示したいとき |

確かさに差があるときは、バッジで分けられます。色ではなく**丸の形**で区別します。

| バッジ | 意味 |
|---|---|
| ●（塗りつぶし） | 裏が取れた・確定 |
| ○（中空） | 当事者の自己申告 |
| ⚬（破線） | 未確認・要検証 |

「調べたことは書いたけど、どこまで確かなのか自分でも曖昧」という資料が、いちばん事故ります。分けて書くと、渡した相手が自分で判断できるようになります。

## 見本

実際に出力した見本です。ブラウザで開けばそのまま読めます。

| 見本 | 型 | 使っている部品 |
|---|---|---|
| [ツールを配る前に、決めごとを3つ書く。](sample-manual.html) | マニュアル | 要約カード・本文＋補足・段組・表・対比 |
| [月いくら払えるか、で決めない。](sample-hikaku.html) | 検討資料 | 要約カード・本文＋補足・表・対比 |
| [3か月で「使える人」を3人つくる。](sample-keikaku.html) | 計画・年表 | 年表・確度バッジ・表 |

見た目は3つのルールで固定しています。

- 影とグラデーションを使わない（面の差と1pxの線だけで階層を作る）
- 有彩色は1色だけ
- ダーク／ライト／システムの3択に対応（右上のボタン）

## 図解キットとの使い分け

同じ見た目の姉妹キットに、[図解キット](https://sankaku-tech.github.io/zukai-kit/) があります。

| | 作るもの | 向いている場面 |
|---|---|---|
| **図解キット** | 1枚の図解 | 長い答えを、ぱっと見て分かる形にしたい |
| **資料キット**（これ） | ページ丸ごと | 章立て・表・年表・出典がある資料を人に渡したい |

迷ったら図解キットのほうが速いです。**章が2つ以上要るなら**、こちらを使ってください。

## 注意

- **AIが作った資料は、元の内容が正しいことを保証しません。** 中身の正しさは必ず自分で確かめてください
- 元の内容にない数字・手順・出典を足さないよう指示してありますが、まれに補って書くことがあります。**特に出典のURLは、実在するか必ず開いて確かめてください**
- 社外に配る資料に使う場合は、固有名詞と数字を最後に自分の目で通してください
